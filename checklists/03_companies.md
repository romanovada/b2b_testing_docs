## Добавление компании

### Первое добавление
- Компанию можно добавить **сразу после регистрации** — на приветственной странице, где одновременно вводятся персональные данные.

### Повторное добавление
- Добавить компанию можно в любой момент, будучи авторизованным.

### Разделы с возможностью добавить компанию

| № | Раздел / Место | Способ |
|:-:|:---------------|:-------|
| 1 | **Сайдбар ЛК** | Кнопка «+ добавить компанию» |
| 2 | **Главная страница** | Блок «Личный кабинет» |
| 3 | **ЛК → Компании** | Кнопка «добавить компанию» |
| 4 | **ЛК → Обращения** | Плашка сверху: «добавить компанию» |
| 5 | **Добавление товара в пустую корзину** | При клике на «в корзину» — попап с кнопкой «+ добавить компанию» (если корзина не пуста, попап **не** появляется) |
| 6 | **Пустая корзина** | Блок с кнопкой «добавить компанию +» |
| 7 | **Корзина с товарами** | При нажатии «перейти к оформлению →» открывается модалка создания компании |

## Создание компании (пошаговый процесс)

Процесс состоит из трёх этапов:

1. **Ввод ИНН**
2. **Проверка данных вводимой компании**
3. **Подтверждение создания** (вывод всех данных компании + новое поле «КПП»; кнопки: подтвердить / отменить)

### Позитивные сценарии (✅)

- [ ] ✅ Ввести корректный ИНН. Система находит организацию.
- [ ] ✅ На шаге 3 нажать «Подтвердить». Компания создаётся.
- [ ] ✅ После успешного создания — появляется попап об успехе.

### Негативные и особые сценарии (❌ / ⚠️)

- [ ] ⚠️ Если компания **уже создана** другим пользователем, на шаге 3 появляется сообщение:
  > *«Компания уже создана на портале. На электронную почту владельца будет отправлен запрос на подтверждение.»*
  - Это действие = **заявка в компанию**.
  - После отправки заявки — попап об успешной подаче заявки.
  - Компания добавится **только после подтверждения** администратором компании.
  - Администратор может отклонить заявку — компания не добавится в ЛК.

## Выход из компании

- Доступно на **странице компании**.

### Сценарии

| Роль пользователя | Возможность |
|:------------------|:------------|
| **Сотрудник** (не админ) | ✅ Доступна кнопка **«покинуть компанию»** → появляется модалка с подтверждением. |
| **Администратор** | ❌ **Не может** покинуть компанию напрямую. <br> ➡️ Необходимо: <br> 1. Добавить нового сотрудника и назначить его администратором. <br> 2. После этого можно покинуть компанию. <br> ⚠️ Если это невозможно — связаться с менеджером для полного удаления компании. |

## Статусы компаний

| # | Статус | Описание | Ограничения |
|:-:|:-------|:---------|:------------|
| 1 | **Активная** | Доступен полный функционал платформы. | — |
| 2 | **На модерации** | Отображается в списке компаний, но функционал ЛК и оформление заказов недоступны. | Нельзя покинуть компанию самостоятельно. |
| 3 | **Приглашение в компанию** | Приглашение можно подтвердить или отклонить. На email приходит уведомление. | Без подтверждения компанию использовать нельзя. |
| 4 | **Заявка подана** | Ожидание подтверждения от администратора. | Можно отменить заявку. |
| 5 | **Новые заявки** | Только для администратора. Можно подтвердить или отклонить заявку от другого пользователя. | Приходит письмо на email администратора. |
| 6 | **Заявка отклонена** | Функционал недоступен. | ✅ Можно удалить карточку компании и подать заявку снова (но есть временной лимит между подачами). |
| 7 | **Отказано в добавлении** | Аналогично статусу 6. | ✅ Можно удалить карточку и подать заявку снова (с лимитом). |
| 8 | **Заблокирована** | Блокируется администратором компании. | Сотрудник не может использовать компанию. Компания **не отображается** в сайдбаре. |

### Группировка статусов по функционалу

- **Функционал заказов и ЛК:** статусы 1, 2, 8
- **Управление сотрудниками и заявками:** статусы 3, 4, 5, 6, 7

## Страница компании

### Доступность

- ❌ Недоступна для неавторизованных пользователей.
- ➕ Для авторизованного без компании — заглушка с маскотом и кнопкой «добавить компанию».
- ✅ Для авторизованного с компанией (любой статус) — страница с данными.

### Отображаемые данные (обязательные *)

- Наименование компании *
- Юридический адрес *
- ИНН *
- КПП
- ОГРН *

### Дополнительные элементы

- Вкладка **«Сотрудники компании (n)»** — если есть сотрудники.
- Кнопки: **«покинуть компанию»** / **«пригласить сотрудника»** (доступны по роли).
- Отображение статуса компании (если не «активна»).
- Блок с дополнительной информацией внизу.
- Интерактивные инфобейджи с тултипами и ссылками на раздел «Помощь».

### Если компания одна

- Сверху — плашка с:
  - информацией о разделе,
  - кнопками: «добавить компанию», «пригласить сотрудника»,
  - ссылкой в «Помощь».

### Если компаний несколько

- Отдельная общая страница со списком карточек всех компаний.
- По клику на карточку → открывается страница конкретной компании (описана выше).
- На странице есть кнопка «добавить компанию».

> ⚠️ Отображение элементов зависит от **статуса** и **роли** пользователя.

## Страница сотрудников

Таблица со всеми участниками компании (сотрудники и администраторы).

### Поля таблицы

1. Сотрудник (ФИО)
2. E-mail
3. Телефон
4. Роль
5. Статус

> 👁 У полей «Роль» и «Статус» есть интерактивный инфобейдж → тултип со ссылкой на раздел «Помощь».

### Возможности администратора

- [ ] ✅ Все сотрудники (кроме самого пользователя) кликабельны.
- [ ] ✅ Можно выделить любое количество сотрудников/администраторов и изменить:
  - **Роль:** сотрудник / администратор
  - **Статус:** активен / заблокирован

### Отображение заблокированных

- По умолчанию **не отображаются** в общем списке.
- Для отображения нужно активировать **свитч-кнопку** (станет зелёной) → заблокированные появляются серым цветом.

### Заявки и приглашения

- Если кто-то подал заявку → появляется **раскрывающаяся плашка** с карточками кандидатов.
- Аналогично — при отправленных приглашениях от администратора.
- Внутри плашки:
  - ФИО, почта, адрес заявки/приглашения
  - Кнопки: **«принять»**, **«отклонить»**
  - Если истек срок действия — кнопка **«отправить повторно»**
- В правом верхнем углу — **крестик** для удаления карточки (автоматически не удаляется).

## Частые ошибки

### Бэкенд
- **502 Bad Gateway** — при создании компании на демо. Компания создаётся в статусе «на модерации».
- **500 Internal Server Error** — при создании компании (связано с работами на бэке).

### Фронтенд (визуальные и логические баги)

- [ ] 👁 Отображение карточек сотрудников и анимации.
- [ ] 👁 Пробелы и отступы между кликабельными словами (ведут в «Помощь»).
- [ ] 👁 Отображение текста (положение и цвет) на мобильных версиях.
- [ ] 👁 Анимированные инфобейджи при взаимодействии.
- [ ] 👁 Корректность работы тултипов.
- [ ] 👁 Счётчики сотрудников внутри компании.
- [ ] 👁 Счётчики в бейдже компании (новые приглашения).

## 📌 Примечания по тестированию

1. **Приоритет:** критические баги — в разделе «Частые ошибки». Но обязательно проверять пункты в каждом разделе, н аразных этапах работы с компаниями.
2. **Кросс-браузерность:** проверять во всех поддерживаемых браузерах (Chrome, Firefox, Яндекс.Браузер, Safari, Edge, Opera).
3. **Адаптив:** все элементы должны корректно отображаться на всех брейкпоинтах (см. `04_breakpoints.md`) во всех браузерах.
4. **Тестовые данные:** использовать заранее подготовленные тестовые ИНН, компании и аккаунты (список тестовых аккаунтов есть в Outline).
