## Универсальные правила валидации

*Эти правила должны работать одинаково во всех формах. Если где-то поведение отличается — это баг.*

### Визуальное поведение (👁)

- [ ] 👁 **Проверить:** При фокусе на поле его нижняя граница подсвечивается белым/серым цветом
- [ ] 👁 **Проверить:** При вводе корректных данных поле подсвечивается зелёным цветом
- [ ] 👁 **Проверить:** При вводе некорректных данных поле подсвечивается красным цветом
- [ ] 👁 **Проверить:** Под полем с ошибкой появляется понятное текстовое описание причины

### Логика работы форм (🔄)

- [ ] 🔄 **Проверить:** При наличии ошибки в поле кнопка отправки формы становится неактивной (задизейбленной)
- [ ] 🔄 **Проверить:** После исправления всех ошибок кнопка отправки становится активной
- [ ] 🔄 **Проверить:** Все сообщения об ошибках отображаются на клиенте и понятны пользователю (без технического жаргона вроде "email must be an email")

## Регистрация

*Отдельная страница регистрации*

### Поле: Логин или рабочая почта

#### Позитивные сценарии (✅)

- [ ] ✅ Ввести валидный email: `test@mail.ru`. Поле подсвечено зеленым, ошибок нет
- [ ] ✅ Ввести email с точкой в локальной части: `test.test@mail.ru`
- [ ] ✅ Ввести email с цифрами: `test123@mail.ru`
- [ ] ✅ Ввести email длиной ровно 70 символов (граничное значение)

#### Негативные сценарии (❌)

- [ ] ❌ Оставить поле пустым. **Ожидаем:** Ошибка "Обязательное поле"
- [ ] ❌ Ввести значение без символа `@`: `testmail.ru`. **Ожидаем:** Ошибка "Неправильный формат почты"
- [ ] ❌ Ввести значение с некорректным доменом: `test@mail`. **Ожидаем:** Ошибка "Некорректный email"
- [ ] ❌ Ввести email на кириллице: `тест@mail.ru`. **Ожидаем:** Ошибка о недопустимых символах
- [ ] ❌ Ввести email длиной 71 символ (превышение лимита). **Ожидаем:** Ошибка о превышении длины
- [ ] ❌ Ввести запрещенные спецсимволы: `"`, `(`, `)`, `\`, `:`, `№`, `;` (проверить каждый)

---

### Поле: Пароль

#### Позитивные сценарии (✅)

- [ ] ✅ Ввести пароль: `Password123` (8 символов, латиница, цифры)
- [ ] ✅ Ввести пароль из 20 символов: `Password1234567890!` (если разрешены спецсимволы)

#### Негативные сценарии (❌)

- [ ] ❌ Ввести пароль из 7 символов: `Pass123`. **Ожидаем:** Ошибка "Минимум 8 символов"
- [ ] ❌ Ввести пароль из 21 символа. **Ожидаем:** Ошибка "Максимум 20 символов"
- [ ] ❌ Ввести пароль кириллицей: `Пароль123`. **Ожидаем:** Ошибка "Только латинские буквы или цифры"
- [ ] ❌ Оставить поле пустым. **Ожидаем:** Ошибка "Обязательное поле"

---

### Поле: Код на email

#### Позитивные сценарии (✅)

- [ ] ✅ Ввести корректный код из письма. Регистрация завершена успешно

#### Негативные сценарии (❌)

- [ ] ❌ Ввести букву в поле для цифр. Буква не должна вводиться
- [ ] ❌ Ввести спецсимвол. Символ не должен вводиться
- [ ] ❌ Ввести неверный код. **Ожидаем:** Ошибка "Код авторизации не найден"
- [ ] ❌ Запросить код на уже зарегистрированный email. **Ожидаем:** Сообщение, что email занят
