## Условные обозначения

| Символ | Значение |
|:------:|:---------|
| ✅ | Позитивный сценарий (корректное отображение / успешное выполнение) |
| ❌ | Негативный сценарий (ожидаем ошибку / ограничение) |
| 👁 | Визуальная проверка (UI/UX) |
| 🔄 | Проверка поведения/логики |
| ⚠️ | Важное замечание или ограничение |

## Общая информация

- Рассылки тестируются на **всех поддерживаемых почтовых сервисах** и **устройствах**.
- Приоритет проверки — **светлая тема**, так как тёмная тема контролируется почтовым сервисом и непредсказуема.
- Общий вес письма не должен превышать **1 МБ**.

## Поддерживаемые почтовые сервисы и темы

### Список сервисов

| № | Сервис | Поддержка тем | Особенности |
|:-:|:-------|:--------------|:------------|
| 1 | **Mail.ru** | Светлая и тёмная | Полная поддержка CSS, адаптивная вёрстка |
| 2 | **Яндекс** | Только светлая | Ограниченная поддержка CSS, частичный адаптив |
| 3 | **Outlook** | Только светлая | PNG-кнопки, ограничения по высоте, адаптив только на macOS/iOS |
| 4 | **Gmail** | Только светлая | Частичная поддержка CSS, обрезание длинных писем |

### Проверка тёмной темы

- [ ] 👁 **Mail.ru (тёмная тема):** Проверить, что цветовая инверсия не нарушает читаемость и не ломает элементы (кнопки, иконки).
- [ ] ❌ **Outlook (тёмная тема):** Не поддерживается. Письмо должно корректно отображаться в светлой теме.
- [ ] ❌ **Gmail (тёмная тема):** Не поддерживается. Письмо должно корректно отображаться в светлой теме.
- [ ] ⚠️ Убедиться, что дизайн не зависит от тёмной темы (использовать единую универсальную цветовую схему).

## Адаптивность и вёрстка

### Уровень поддержки

| № | Сервис | Уровень адаптивности |
|:-:|:-------|:---------------------|
| 1 | **Mail.ru** | ✅ Полный адаптив |
| 2 | **Gmail** | ✅ Полный адаптив |
| 3 | **Outlook (macOS/iOS)** | ✅ Полный адаптив |
| 4 | **Яндекс** | ⚠️ Частичный адаптив (desktop-версия адаптируется по ширине, но элементы управления могут отображаться некорректно) |
| 5 | **Outlook (остальные версии)** | ❌ Только desktop |

### Общие проверки

- [ ] ✅ Письмо корректно отображается на всех разрешениях (десктоп, планшет, мобильные).
- [ ] ✅ Текст читается без масштабирования на экране шириной 320 px.
- [ ] ✅ Touch targets (кликабельные элементы) имеют размер не менее 44×44 px.
- [ ] 👁 На мобильных версиях блоки перестраиваются корректно (горизонтальное расположение → вертикальное).
- [ ] 👁 В Яндексе две карточки в строке не превращаются в одну (проверить на сломанную вёрстку).
- [ ] ✅ Для карточек товаров используется вертикальный layout (1 карточка = 1 строка) для гарантированного отображения.

## Шапка письма (Header)

### Логотипы

- [ ] 👁 **Формат:** Логотип сохранён в формате PNG.
- [ ] 👁 **Размеры:** Фиксированные, единые для desktop и mobile.
- [ ] ✅ **Alt-текст:** Присутствует осмысленный замещающий текст (не `image1.png`).
- [ ] ✅ **Кликабельность:** Вся область логотипа кликабельна и ведёт на главную страницу.
- [ ] ⚠️ **Отключенные изображения:** Проверить, что при отключенных изображениях отображается только текст `alt`.
- [ ] 👁 **Универсальность:** Логотип не меняется в зависимости от темы (используется одна универсальная версия).

### Фоновые изображения (Header)

- [ ] 👁 **Размер:** 600×300 px.
- [ ] 👁 **Позиционирование:** Центрирование только по горизонтали, вертикаль — `center`.
- [ ] ✅ **Адаптив:** При адаптации контейнер меняет размер, изображение не масштабируется, меняется только центрирование.
- [ ] ✅ **Поддержка:** Проверить в Mail.ru и Outlook (macOS/iOS).
- [ ] ❌ **Остальные сервисы:** Фоновые изображения не применяются (используется сплошной цвет).
- [ ] ⚠️ Фон не может меняться в зависимости от темы.

### Декоративные элементы

- [ ] 👁 Бордеры используются только по необходимости (максимум 2 цвета).
- [ ] 👁 Вертикальные линии минимизированы и используются только с текстовыми блоками.

## Тело письма (Body)

### Ограничение по высоте

- [ ] ✅ Общая высота письма (Header + Body + Footer) не превышает **2800 px**.
- [ ] ⚠️ **Outlook:** Проверить, что письмо не обрезается.
- [ ] ⚠️ **Gmail:** Проверить, что письмо не сворачивается с кнопкой "…".

### Оптимизация высоты

- [ ] 👁 Пустое пространство минимизировано.
- [ ] 👁 Изображения сгруппированы в коллажи (для дайджестов новостей).
- [ ] 👁 **Outlook:** Для списков новостей используется одно изображение-коллаж вместо отдельных картинок.

### Маскоты

- [ ] 👁 **Формат:** Одно изображение на все адаптивы.
- [ ] ✅ **Масштабирование:** Изображение масштабируется по ширине письма.
- [ ] 👁 **С отступами:** В общем блоке с контентом (стандартный вариант).
- [ ] 👁 **На всю ширину:** Отдельный блок с фоном и отступами.
- [ ] ⚠️ При использовании фонового изображения на всё тело письма, маскот должен иметь отступы от краёв.

### Фоновые изображения (Body)

- [ ] ✅ Подложка на всё тело письма допустима.
- [ ] ❌ **Outlook:** Вставка фона невозможна и ломает вёрстку (проверить отображение).

## Кнопки

### Размеры и структура

- [ ] 👁 Ширина кнопки = Текст + Иконка + Padding + Отступы.
- [ ] 👁 Минимальная ширина кнопки — 250 px.
- [ ] ✅ Для длинного текста используется стандартная вёрстка с padding (без фиксированной ширины).
- [ ] ✅ **Outlook:** Кнопка сохранена как PNG-изображение (только desktop).

### Текст на кнопках

- [ ] ✅ Текст короткий и читаемый (например: "Смотреть товары", "Оформить заказ").
- [ ] ❌ Текст не переносится на вторую строку (проверить на кнопках с длинными названиями).
- [ ] 👁 Текст на кнопках читается без масштабирования на мобильных устройствах.

### Иконки

- [ ] 👁 **Формат:** PNG (не SVG).
- [ ] ✅ Иконки предварительно загружены для отображения (особенно в Gmail).
- [ ] 👁 Иконки корректно отображаются на всех сервисах.

### Цветовая схема

- [ ] 👁 Основной цвет кнопок — зелёный (рекомендуется).
- [ ] 👁 Альтернативный цвет (чёрный) инвертируется в белый на тёмной теме (проверить).
- [ ] ⚠️ Избегать инверсий в блоках с фотографиями.
- [ ] 👁 Единый цвет остаётся узнаваемым во всех темах.

## Карточки товаров

### Расположение

| № | Вариант | Поддержка | Проверка |
|:-:|:--------|:----------|:---------|
| 1 | 1 карточка/строка | Универсально | ✅ Рекомендуется использовать по умолчанию |
| 2 | 2 карточки/строка | Mail.ru, Gmail, Outlook | ⚠️ В Яндексе может сломаться (проверить) |

- [ ] 👁 **1 карточка/строка:** Отображается корректно на всех сервисах.
- [ ] ⚠️ **2 карточки/строка:** Проверить в Яндексе — не превращаются ли в одну.

### Изображения товаров

- [ ] 👁 **Форма:** Строго прямоугольная.
- [ ] 👁 **Размеры:** Точно по макету (например, 220×210 px).
- [ ] ❌ Изображения меньше заданных размеров по любому из параметров не используются (проверить).

### Кликабельность

- [ ] ✅ **Кликабельны:** Изображение товара, текстовые элементы (название, цена).
- [ ] ❌ **Не кликабельна:** Область всей карточки целиком.

## Футер (Footer)

### Блок контактов

- [ ] 👁 Схема расположения: 3 элемента в строку или 2×2.
- [ ] ✅ Адаптив: Горизонтальное → вертикальное расположение.
- [ ] 👁 Количество элементов фиксировано для всех версий (если 3 на desktop, то 3 на mobile).

### Разделители

- [ ] 👁 Единый цвет для всех тем.
- [ ] ⚠️ **Outlook:** Дополнительные полосы из-за округления высоты текста — не ошибка вёрстки (проверить, что при изменении масштаба они исчезают).

### Веб-версия письма

- [ ] ✅ Кнопка перехода на веб-версию работает корректно.
- [ ] 👁 Отображение веб-версии соответствует адаптивам Figma.

### Актуальность данных

- [ ] ✅ Контактная информация и текстовые блоки футера актуальны для текущей рассылки.
- [ ] ✅ Для системных писем (постоянные шаблоны) данные актуальны.

## Переменные и персонализация

- [ ] 🔄 **Динамические данные** заключены в двойные фигурные скобки: `{{user_name}}`, `{{order_number}}`, `{{promo_code}}`.
- [ ] ✅ Переменные корректно заменяются на фактические данные.
- [ ] ✅ Если данные отсутствуют, переменная отображается как пустая строка или стандартное значение (не ломает вёрстку).

---

## Вес письма и изображения

- [ ] ✅ Общий вес письма не превышает **1 МБ**.
- [ ] ✅ Каждое изображение весит не более **200 КБ**.
- [ ] 👁 **Формат изображений:** PNG (для иконок/логотипов) и JPG (для фото).
- [ ] ✅ Alt-текст осмысленный для всех изображений.

---

## Доступность (Accessibility)

- [ ] ✅ Логическая структура заголовков (h1 → h2 → h3).
- [ ] ✅ Ссылки описательные (например, "Скачать прайс-лист" вместо "Нажмите здесь").
- [ ] ✅ Контраст цветов соответствует требованиям (минимум 4.5:1 для текста).
- [ ] 👁 При отключенных изображениях письмо остаётся читаемым.
- [ ] ✅ Проверено отображение в режиме "Только текст".

## Частые ошибки

### Бэкенд / Системные ошибки
- [ ] ❌ Ошибка 500 при генерации письма.
- [ ] ❌ Ошибка 502 при отправке через демо-среду.
- [ ] ❌ Не отправляются письма с большим весом (>1 МБ).

### Фронтенд (визуальные и логические баги)

| Ошибка | Проверка |
|:-------|:---------|
| SVG-иконки | ❌ Не отображаются в Outlook. Использовать PNG. |
| Градиенты в кнопках | ❌ Превращаются в сплошной цвет. Использовать сплошные цвета. |
| Фоновые видео | ❌ Не поддерживаются. Использовать статичное изображение с кнопкой play. |
| Слишком много колонок | ❌ Схлопывание в мобильной версии. Максимум 2 колонки. |
| Непропорциональные изображения | ❌ Искажение пропорций. Строгое соблюдение размеров макета. |
| Отсутствие Alt-текстов | ❌ При отключенных изображениях теряется смысл. Alt-текст обязателен. |
| Длинный текст на кнопках | ❌ Перенос текста на вторую строку. Текст кнопок должен быть коротким. |
| Неактуальные контакты в футере | ❌ Ввод пользователей в заблуждение. Данные должны быть актуальны. |

## 📌 Примечания по тестированию

1. **Приоритет:** Критические баги — в разделе «Частые ошибки». Однако обязательно проверять все пункты чек-листа для каждого типа рассылки.
2. **Кросс-браузерность и кросс-платформенность:** Проверять во всех поддерживаемых почтовых сервисах (Mail.ru, Яндекс, Outlook, Gmail) на всех устройствах (десктоп, планшет, телефон). Отдельно проверять веб-версию.
3. **Адаптив:** Проверять на всех брейкпоинтах (см. макеты Figma).
4. **Тестовые данные:** Использовать тестовые почтовые ящики на всех поддерживаемых сервисах.
5. **Реальные устройства:** Проверять письма не только в эмуляторах, но и на реальных устройствах (iOS, Android, Windows, macOS).
6. **Отключение изображений:** Проверять читаемость письма при отключенных изображениях.
7. **Тёмная тема:** Проверять только в Mail.ru (в остальных сервисах — только светлая тема).
